## F1 Telemetry 2.0: a window of its own on Windows

On Windows, F1 Telemetry now opens in its own window instead of a browser. macOS and Linux work as before.

### What's new

- **Its own window:** the whole dashboard opens in an F1 Telemetry window, which remembers its size and the monitor it was on. Closing it keeps the app in the notification area. Starting the app again brings the window up.
- **The race engineer in its own window:** the voice cockpit alone: the engineer, what it said and what you asked, volume and the radio switch, and a strip with your position, fuel, tyres and damage. It runs from the start, hidden until you open it (**Race engineer** in the tray menu, or **Open the engineer window** on Live), so the engineer talks whatever page the main window shows, and closing it keeps it talking.
- **One radio per PC:** on the PC running the app, only the engineer window speaks and listens to push-to-talk, so nothing talks over it. Phones and tablets keep their own switch.
- **Settings → App:** the version and **Update now**, whether the window opens when F1 Telemetry starts, **Start with Windows**, the address for a phone or tablet, and **Quit**. On that PC the release notes have **Update now** too, and after an update the window opens on Settings → App.
- **An installer:** `f1telemetry_<version>_windows_amd64_setup.exe` installs F1 Telemetry for your user (no administrator prompt) with a Start menu shortcut, and installs Microsoft's WebView2 Runtime if the PC needs it. The portable zip is still here.
- **Links outside:** release notes, AI provider pages and links in AI answers open in your default browser.

### Coming from 1.x on Windows

- **Update now** in 1.x installs 2.0 in the same folder, with your sessions and settings. 1.x's small window then says F1 Telemetry has its own window: click **Open F1 Telemetry** and it closes.
- You no longer need Live open behind the game: the engineer runs in its own window from the moment F1 Telemetry starts, and a browser tab on the same PC no longer speaks.
- The app's windows keep their own **This device** settings (volume, radio effects, language, units, views), so set them once in Settings → This device; both windows follow. The engineer's voice, push-to-talk and AI keys carry over.
- Push-to-talk speech in the window is recognized by Microsoft's service, as in Edge, instead of Chrome's. If the engineer doesn't understand you, the `Push-to-talk transmission` lines in the log (tray → **Open log file**) say why.
