# F1 Game Telemetry Project Rules

Architectural boundaries, invariants, and verification gates.

## 1. Mandatory Verification & Testing
* **Pre-Completion Gate:** NEVER mark a task complete without passing all checks below:
  1. **Go Format & Linters:** `gofmt -l .`, `go vet ./...`, `golangci-lint run` (0 issues; vet + lint also with `GOOS=windows`).
  2. **Generated Wire Types:** `go run ./cmd/tsgen -check` (0 stale; `make gen-types`; `TestGeneratedFilesUpToDate`).
  3. **Go Backend Tests:** `go test -race -count=1 ./...` (100% pass, no cache; table-driven tests for parsers/errors).
  4. **Frontend Lint:** `npm run lint` (`oxlint` + `jsx-a11y`) in `frontend/` (0 errors).
  5. **Frontend Tests:** `npm test` (`vitest`, Testing Library; 100% pass).
  6. **Production Build:** `npm run build` (`tsc -b && vite build`, 0 errors).
  7. **Reporting:** Report real test counts, lint and build results.
* **UDP Simulator (`cmd/simulator`) & Helpers:**
  - `make simulate` (2026: 22 cars + 2 observers; `FORMAT=2025`: 20 + 2) or `simulate.bat` sends every packet type at 20Hz (`CarTelemetry2` for 2026).
  - Scenarios (`-scenario <name>`): `wear`, `sc`, `vsc`, `rain`, `start`, `pit`, `qualy`. `run.bat` builds and launches the embedded Windows binary.

## 2. Clean Code, Constants & Principles
* **Zero Magic Numbers / Literals:** No hardcoded numbers, status codes or hex colors in Go/TS.
* **Go Constants:** `internal/packets/constants*.go` as `packets.*` (`ResultStatusFinished`, `MillisPerMinute`, `DriverName(...)`, `SessionTypeName(...)`).
* **Frontend Constants:** `frontend/src/constants/f1.ts` (`PACKET_IDS`, `RESULT_STATUS`, `PIT_STATUS`, `SESSION_TYPES`, `TIME_CONSTANTS`, `RACE_CONTROL_LAYOUTS`).
* **Principles:** **DRY** (reuse constants, wire types, helpers, hooks), **Separation of Concerns** (thin HTTP handlers; domain logic in `internal/{analytics,session,engineer}`; presentation in React + Zustand), **KISS & YAGNI** (no speculative abstractions).

## 3. Technology Stack & Architecture
* **Platform & Spec:** Windows 10/11, macOS, Linux. Exclusive to **F1 2025** & **F1 2026 DLC** UDP (`PacketFormat` 2025/2026, 29-byte `PacketHeader`; ≤2023 deprecated). Vite (`frontend/dist`) embeds via `//go:embed` (`frontend/embed.go`), served with SPA fallback (`setupStaticRoutes`) + `system.OpenBrowser`.
* **Backend Packages (`internal/`):**
  - `api/`: HTTP router, decoding, middleware, serialization only (**zero domain/analytical logic**). Enforces `http.CrossOriginProtection`, no CORS headers, `MaxJSONBodyBytes` (2 MB) on `/api`, `MaxImportPayloadSize` (100 MB) on `/api/sessions/import`.
  - `udp/`: Non-blocking UDP listener (`Listener`).
  - `packets/`: 1:1 binary UDP decoders/constants. **Gotcha:** in `PacketLapData`, `LapDistance` and `TotalDistance` (`float32`) sit right before `SafetyCarDelta`.
  - `session/`: `SessionManager`, `LapTracker`, `TelemetryBatchWriter`, `LiveBroadcaster` (10 Hz `LiveSnapshot` + `FeedEvent`), ZIP import/export.
  - `analytics/`: Standings, `MergeLapComparisonCached` (5m grid), progression matrices, stint degradation OLS regression, `TrackProgressResponse`, `ChatContextSource` (`ai.RecordedRaceSource`).
  - `engineer/`: Strategy engine (`EngineerEngine`, `EngineerRule`), race history (player laps, rival histories, events, radio calls), live context (`RaceContext()`, `LiveBriefing()` as `ai.LiveRaceSource` at `GET /api/ai/engineer/race-context`), `RaceTools()` (`race_tools*.go` as `ai.ToolExecutor`).
  - `ai/`: Providers (`gemini.go`, `openai.go`, `claude.go` on `anthropic-sdk-go`, OpenAI-compatible `custom`) + Edge neural TTS. `provider.go` is the registry (`DefaultModel()`, `ServerKeys`, models, `chatSession`). `chat.go` runs the tool loop over `ChatOptions.ToolExecutor` (≤ `MaxToolRounds`, last round without tools, retry without tools if rejected), streaming text + `[DONE]`. API keys in headers only; `custom` uses only the request key.
  - `storage/`: CGO-free `modernc.org/sqlite`, migrations (`schema_version`), `MarshalJSON` sanitization, `EncodeLapTelemetry` lap BLOBs (`lap_telemetry`, `ON DELETE CASCADE`; `.f1session` 2.0) ≤ 20 Hz (`ThinSamples`). **Session UIDs must always be stored/serialized as Hex strings** (`TEXT`, `0x...`).
  - `settings/`: Shared JSON settings (`settings.Sections`: `ai`, `voice`, `ptt`, `engineer`, `comparator`).
  - `locales/`: Type-safe `PromptCatalog`, registry (`Resolve`, `Get`), `en`/`es` catalogs (no boolean flags).
  - `input/`: Global PTT (`winmm.dll` DirectInput wheels, `user32.dll` keyboard on Windows; Gamepad API + `Space` fallback).
  - `system/`: Version metadata, GitHub update check (`system.DefaultGitHubRepo`), network discovery (`DescribeTelemetryEndpoint`), `OpenBrowser`/`OpenPath`, `FindRunningInstance` (2nd launch exits quietly).
  - `desktop/`: `App` behind loopback-only `/api/desktop` (`system.OpenAppWindow`, `LoadDesktop`, HKCU `Run`, Quit). Tray (`fyne.io/systray` only in `_windows.go`; `onExit` = shutdown), en/es by OS, dialogs; stubs elsewhere. Release `-H=windowsgui`, log by DB. Icons: `go generate`.
  - `tsgen/`: Standard-library Go-to-TS wire type generator (`cmd/tsgen`).

### Wire Types & REST Contracts
* **Wire Types (`cmd/tsgen` → `frontend/src/types/generated/`):**
  - Generated per Go package from `cmd/tsgen/main.go`: REST responses, `ai.AIChatRequest` (`ChatContextMode`), `EngineerSocketMessage` (`EngineerDirective | PTT*Message | SettingsChangedMessage`, `SettingsSection`, `EngineerAlertKey`, `EngineerDirectiveCategory`, `EngineerUrgency`), `session.FeedEvent` (`FeedEventCode`, `FeedEventType`, `FeedSeverity`), `session.LiveSnapshot`. Never edit generated files or hand-copy wire types.
  - `internal/tsgen` uses `tstype:"..."`, `TypeAlias` (`[]map[string]any`), `Marshaler` (`MarshalJSON`, `TestMarshalerKeys`). Responses must be named structs, never `map[string]any`.
  - `types/*.ts` re-export generated types (`types/telemetry.ts`: `LapData`, `Car*Data`, `ParticipantData`, `SessionData`), narrow unions via `Narrows<T, Base>` (`types/wire.ts`), and tests use `test/wireFactories.ts` (`makeLive*`).
* **REST Errors & Client (`utils/apiClient.ts`):**
  - Non-OK responses return `{"error","code"}` (`api/response.go`). Failed `POST /api/sessions/import` (400) sets `error` to first `details[].reason`. Batch export: `POST /api/sessions/export-batch` (`{"session_ids":[...]}`). Frontend calls REST only via `apiClient.ts` (`request()` → `ApiError.message`; `api.stream()` → raw `Response` for `sseUtils.ts`).

### Settings Ownership & Cross-Tab Sync
* **Server Settings (`GET`/`PUT /api/settings/{ai,voice,ptt,engineer,comparator}`):**
  - API keys are write-only. AI resolution: request → saved → env (`*_API_KEY`, `LLM_PROVIDER`, `LLM_MODEL`) → default (`internal/ai`). Startup: flags → env → `.env`.
  - **Engineer (`settings.Engineer` under `engineer_config`):** Stores `engineer.Tuning`, `trigger_preset`, `alert_switches` (`engineer.AlertSwitchKeys` → `EngineerAlertSwitch` vs `ALERT_TOGGLE_KEYS`), loaded over `settings.DefaultEngineer()`. `Engineer.EngineConfig()` builds runtime config (`EnabledCategoriesFromSwitches`, missing = on, + `DefaultEngineerConfig()`); browser never sends `EnabledCategories`/server constants and reads defaults from `GET /api/settings/engineer/defaults`.
  - **Concurrency & Sync:** Engineer PUTs carry `version`; server bumps it, returning `409` (`SETTINGS_CONFLICT`) on stale saves (UI reloads + notice). PUT decodes over saved setup and broadcasts `settings_changed` (`section`, `source` from `X-Dashboard-Client`, `version`) on `/ws/engineer`.
  - **Client Sync (`utils/settingsClient.ts`):** Saves via `putSettings(section, body)` (`DASHBOARD_CLIENT_ID`), listens via `subscribeSettingsChanges` (ignoring own tab): `SettingsSync.tsx`, `useAISettings`, `usePTTConfig` reload on change. Engineer saves debounce (`syncConfigToBackend()`). Failed saves report to `useSettingsSaveStore` (`reportSettingsSaveFailure`); never swallow errors.
* **Per-Device `localStorage` (`utils/storage.ts`):**
  - Only via `utils/storage.ts` (raw values via `getString`/`getBoolean`/`getNumber`), with every key in its `KnownStorageKey` union: per-browser preferences, plus legacy keys read once to migrate to the server.
  - **Settings page (`components/settings/`, `SETTINGS_SECTIONS`):** dialogs stay shortcuts (`AllSettingsLink`); its views read a store. New shared section = Go `settings.Section*` + handlers + tsgen, a store moving old browser keys once (`useComparatorPreferencesStore`), `SettingsSync`, a page section.

### WebSockets, Live Telemetry & AI Chat
* **WebSockets (`utils/websocketClient.ts`):** Keep gorilla `CheckOrigin` (never override). `/ws` and `/ws/engineer` are ref-counted singletons via `createSharedSocket(path)` (`connectTelemetryWebSocket`, `subscribeEngineerMessages` in `utils/engineerSocket.ts`). `/ws/engineer` drops unknown types; server sends API events via `Server.broadcastEngineer` and directives via `EngineerEngine`.
* **Live Snapshot (`/ws`) & Status:** Only Live tab opens `/ws`; other pages poll `GET /api/system/status` (`api.SystemStatus`: UDP addr, `packet_age_ms`, session from `LiveBroadcaster.FeedStatus()`) via ref-counted `subscribeSystemStatus` (`useSystemStatusStore`; stale after 3s, listening after 60s). `useLiveStatus()` (`offline | listening | live | stale`) drives nav badge, header, title, `LiveSessionToast` (never `"LIVE"` just because the backend answers). UDP port/LAN IPs come from `GET /api/system/network` (`useTelemetryEndpointStore`; never hard-code 20777). `/ws` sends only 10 Hz `PacketIDLiveSnapshot` (255) DTO (`session.LiveSnapshot`: `ActiveCarCount` rows, live-view fields, filled forecasts, no marshal zones; checked by `TestLiveSnapshotPayloadSize`). Add new live fields to `Live*` + `toLive*` in `live_snapshot.go` and run `make gen-types` (never send raw packets). `GapAheadTrend`/`GapBehindTrend` (`LiveGapTrend`, ms/lap) come from `EngineerEngine.GapTrends()` via `SetGapTrendSource`. `LapTimes` (`LiveLapTimes`: last/best sectors, best lap) come from history packets `LiveBroadcaster` keeps (`CarHistory`, also behind `GET /api/live/cars/{i}/laps` for `CarDetailDrawer`); never derive S3 from current-lap sectors. Store: `bestLapTimes` (`mergeBestLaps`, history best wins), `allLapTimes`, trends.
* **Race-Control Feed (`internal/session/feed_events.go`):** `LiveBroadcaster` turns Packet ID 3 + derived events (pit entry, penalty, retirement, DSQ, SC) into `session.FeedEvent` (`FeedEventCodes`, type, severity, typed params; no text), sent in `LiveSnapshot.Events` and `FeedEventSink` (`SessionManager.RecordFeedEvents`, stamping leader `RaceLap` in `session_events`). `utils/raceEvents.ts` formats `en`/`es` text via exhaustive switch on `FeedEventCode`.
* **AI Chat (`/api/ai/chat`):**
  - `POST /api/ai/chat` sends only IDs in `context` (`ai.ChatContextRequest`: `context_mode`, `session_id` + `focus` (open session tab; `BuildDebriefFocus` adds its data), or `lap_a_id`/`lap_b_id`/`zoom`); browser never writes prompts/summaries. `ai.BuildChatContext` builds prompts on server (`LiveRaceSource`, omitted when stale, or `RecordedRaceSource`) + saved `DriverCallsign`/`CustomPrompt`, with driving phase / 2026 rules / incident status from engine briefing only; both unknown IDs (404) and bad context (400) return `INVALID_REQUEST`.
  - `RaceEngineerContextDefinitions.ts` splits `useRaceEngineerActions()` (stable ref callbacks), `useRaceEngineerState()` (window, URL targets via `chatTargetsFromRoute`, AI settings), `useRaceEngineerStream()` (messages) so pages never re-render per chunk (`App.rerender.test.tsx`). `AskAiButton` asks about its chart. Docked chat (`<html data-chat-docked>`, above `--laptop`): fixed right-side UI offsets by `--chat-dock-space`.
  - SSE (`internal/ai/sse.go`, `utils/sseUtils.ts`) streams `data: {"text":...}` + `data: [DONE]`, or final `data: {"error","code","provider","message"}` frame (`aiErrorPayload` / `classifyAIError`), read by `readChatStream`/`chatStreamErrorFromResponse` (`ChatStreamError`; unanswered = `NETWORK_ERROR`). `POST /api/ai/models` returns filtered chat models; `ChatSettingsDrawer` uses `AI_SERVER_PRESETS`. Markdown renders via `utils/markdown.ts` + `ui/Markdown.tsx` (no raw HTML).

### Recorded Sessions, Player Car, Comparator, Progress & Routing
* **Session Detail & Cache:** `GET /api/sessions/{id}/detail` (`analytics.ComputeSessionDetail`, checked by `TestSessionViewPayloadSize`) loads session, participants, laps, `session_events` once. `participants`/`laps` are top-level (`DriverStanding`/`DriverStint` omit slices via `json:"-"` and join in `normalizeDriverStanding`). `sessionDataCache.ts` caches ≤ `SESSION_DATA_CACHE_LIMIT` sessions (`useSessionDetail` primes; comparator shares `getSessionLapData`; delete/import invalidates).
* **Story & Stints:**
  - Detail tabs: `story | classification | pace | position | gap | stints | sectors` (`SESSION_DETAIL_TABS`; `RACE_CHART_TABS` for races). `analytics.RaceControlPeriods` + `utils/raceStory.ts` (`raceControlPeriods`, `keyMoments`, `momentsByLap`, `fieldPace`) power `SessionStoryTab` (`YourRaceCard`, `FieldPaceChart`, `SessionDebriefPanel`, `KeyMomentsTimeline`) + SC/VSC shading (`raceControlAreas`).
  - `ComputeSessionStints` fits OLS `degradation_slope` (≥3 clean laps) + `avg_lap_time_ms` after `stintExclusions` (`pit_in`/`pit_out` via `analyzeDriverLapOutliers`, `sc`/`vsc` via `neutralisedLaps`, `slow` > 107% of remaining median; stored at `{key}_excluded`/`{key}_reason`). `DegradationCurves.tsx` plots excluded laps as hollow dots, y capped at 107% of median.
* **Player Car & Session List:**
  - `sessions.player_car_index` + `player_car_source` (`'game' | 'user' | null`) store player car (`saveSession` never overwrites `'user'`). `PUT /api/sessions/{id}/player` sets/clears car; `POST /api/sessions/batch-player` matches `Participant.DisplayName()` case-insensitively (`{updated, not_found, ambiguous}`). `GET /api/sessions` returns `SessionListItem` with `summary` (leader, fastest lap, laps, `player` via `FindPlayerStanding`).
  - Client: `utils/player.ts`, `PlayerPickerModal`, `BatchDriverModal`, `utils/sessionListView.ts`, `useSessionListPaging` (50 per page). `getTrackInfo` matches exact names/aliases before substrings.
* **Comparator & Progress:** Defaults use `resolveReferenceLap` (Slot A: `player_car_index` with fastest-lap fallback) + `resolveComparisonLap` (Slot B: shared `comparator` settings), `comparatorQuickStart.ts`, `CornerTable.tsx` (`analyzeCorners` in `utils/trackTurns.ts`, syncing URL `zoom` + AI chat), `StripCharts.tsx` (`stripTraces.ts`, `normalizeStripLayout`). `GET /api/progress?track=` (`ComputeTrackProgress`) powers `/progress[/:track]` (`useTrackProgress`, `progressStats.ts`), returning `ProgressTracks`, `ProgressSession` (`consistency_ms`: std dev of ≥ `MinConsistencyLaps` clean laps), `unmatched_sessions`.
* **URL Routing (`router/`):** History API router in `routes.ts` (`parseRoute`, `buildPath`, `useRoute()`, `navigate()`, `Link`): `/history`, `/history?quick=&track=` (`Route.listFilter`, applied once), `/history/:sessionId[/:tab]` (`story` if omitted; `/charts` → `pace`), `/compare?sa=&a=&sb=&b=&zoom=`, `/progress[/:track]`, `/live/:mode` (`dashboard` | `cockpit` | `driver`), `/settings/:section`. `/` reopens last page, `/live` last live mode (phones keep their own, default `driver`: `DriverGlance`, `useScreenWakeLock`), unknown paths → `/history`. New pages/sessions push history; within-page changes (detail tab, comparator laps/zoom, live mode) `replace` it. New routes: `routes.ts`, its tests, `TestHandleEmbeddedFrontendAndSPAFallback`. `/desktop` (app window): `main.tsx`, not `routes.ts`.

## 4. F1 Telemetry & Radio Protocols
* **Proactive Radio:** Directives on `/ws/engineer` carry `sub_alert` (`engineer.RadioAlertKeys`), category, urgency, `ttl_ms`, `box` (rule's `BoxCall` + pit entry learned in `pit_lane.go`; late non-urgent orders wait for line; UI adds `box_timing_phrases`), `values` (UI placeholders, `report_phrases`), no wire text (`Title`/`Message` server-only). UI maps `EngineerAlertKey` (`constants/radioAlertCategories.ts`), picks phrase from `locales/{en,es}/radio_phrases.ts` (`getProactiveRadioSpeech`). PTT: `[DRIVER RADIO TRANSMISSION]` (`useRadioAudio.ts`); `cleanRadioSpeechText` strips bracketed tags. **No "Entendido"/"Copy"/"Roger" openers on proactive calls** (PTT replies only). Address driver as "you".
* **Phases & Audio (`DrivingPhase`):** `PhaseFlyingLap`/`PhaseGrid`/`PhaseRaceStart` (to `RaceStartPhaseDistanceM`): critical/`BreaksRadioSilence` only; `PhaseRedFlag` from `RDFL`/count up to restart; `PhaseInGarage`/`PhasePitLane`: calls wait while stationary/on limiter. `gateDirectiveLocked`: switch/phase/dedup/`MinRepeatMs` (any urgency) drop; pause/discretion/cooldowns hold per key up to `MaxDelayMs`. `useTTSPlayback.ts` skips stale calls (urgent cut routine, queue behind urgent), streams PTT replies per sentence (`createSentenceChunker`, `beginReplyStream()`). Penalties supersede corner-cutting warnings; SC/VSC/yellow shield (`0.35s <= delta <= 3.0s`).

## 5. UI/UX, Design Tokens & Accessibility
* **Design Tokens (`styles/base/variables.css` & `theme.ts`):** `--bg-*`, `--text-*` (≥ 4.5:1), `--accent-*`, `--status-*`, `--f1-*`, `--weather-*`, `--chart-*`, spacing, type, radius, shadow, glow, control heights, `--z-*` (`nav < docks < popovers < dialogs < toasts < tooltips`), motion. Colour meanings: its header comment. Fonts: `@fontsource-variable` (`styles/index.css`). Sticky: `top: var(--sticky-top)` (`useNavHeightVar`). No raw colors in components. Show speeds/temps/clock times only via `useUnits()` (data stays km/h/°C), session types via `sessionTypeLabel` (stored names stay English). TS reads tokens via `styles/theme.ts` (`cssVar`, `getCssVars`, `alpha`, `canvasRgba`, `styleVars`, `THEME_TOKENS` checked by `theme.test.ts`; no hex alpha like `${color}40`). Use `TYRE_COMPOUNDS` / `getVisualCompoundId`, `getTeamColor(teamId)` (`constants/f1.ts`). Charts: `charts/chartTheme` + `ChartLegend`.
* **Accessibility & Primitives (`styles/base/accessibility.css`, `components/ui/`):**
  - Global `:focus-visible` ring (`--focus-ring-color`; only text fields drawing own focus state may set `outline: none`), `.sr-only`, `prefers-reduced-motion`; performance mode (`<html data-performance>`, `base/performance.css`); JS: `shouldReduceMotion()`. Clickables are `<button>` (`.button-reset`) or `Link` with ARIA state (`aria-pressed`/`-expanded`/`-selected`/`-current`, `aria-sort` on `<th>`; clickable rows/cards/backdrops keep `onClick` only as `role="presentation"` shortcut for a real button). Color is never sole cue (`SectorTime.tsx`). Toasts use always-mounted `aria-live="polite"` region (`role="alert"`: errors).
  - Reuse `components/ui/` (`Button`/`IconButton`, `Modal`, `Menu` + `roving.ts`, `Panel`, `PageHeader`, `Badge` (`tone="you"`), `Chip`, `Callout`, `Tabs`, `SegmentedControl`, `DataTable`, `Stat`, `Switch`, `Slider`, `TextInput`/`TextArea`/`Select` in `Field.tsx`, `EmptyState` (no bare loading/empty text), `Skeleton*`, `Tooltip`/`useTooltip`, `Markdown`, `useDialogLayer`, `cx.ts`) with CSS Modules (`Name.module.css`); `composes:` from `ui/patterns.module.css` (`popover`, `tile`, `eyebrow`, `subheading`, `teamEdge`, `you`, `selected`, `numeric`; don't override their properties); pages compose `styles/page.module.css` (`--page-gutter`).
  - **Breakpoints:** `@media (--phone)` (≤600px), `(--tablet)` (≤900px), `(--laptop)` (≤1100px) from `styles/breakpoints.ts` (`breakpointMedia` in `vite.config.ts`, enforced by `breakpoints.test.ts`) or `useMediaQuery(maxWidth(...))`. Tests: roles, labels, `data-*`, not class names.

## 6. Multi-Language, CI/CD & Documentation
* **Localization:** `locales/en/` is base schema, always bundled; others load on demand (`loadLocale`, preloaded in tests); radio phrases load with Live (`utils/radioPhrases.ts`). Backend (`internal/locales`) uses `PromptCatalog` (`EnglishCatalog`, `SpanishCatalog`), thread-safe `Resolve`/`Get`, Edge TTS voice mappings without boolean flags. `I18nProvider` + `useI18n` (`context/`) support `en` and `es` (`"Español (Latinoamérica)"`), saved as `f1_telemetry_language`.
* **CI & Docs:** Add new tests, generators or linters to `.github/workflows/ci.yml`. Update docs on architecture/flag/feature changes: `README.md`, rules in `.agents/AGENTS.md` (`< 20 KB`, so it never truncates).
